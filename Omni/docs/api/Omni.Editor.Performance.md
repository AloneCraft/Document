# <a id="Omni_Editor_Performance"></a> Namespace Omni.Editor.Performance

### クラス（Classes）

 [OmniPerformancePlayerBuilder](Omni.Editor.Performance.OmniPerformancePlayerBuilder.md)

Build Settingsを変更せず、許可済み段階Sceneまたは製品Sceneだけを含むIL2CPP性能計測Playerを生成します。

 [OmniProfilerCaptureExporter](Omni.Editor.Performance.OmniProfilerCaptureExporter.md)

Unity Profilerの.dataを読み込み、全体値とRuntime限定値をJSON/CSVへ分けて出力します。

 [OmniProfilerCaptureSession](Omni.Editor.Performance.OmniProfilerCaptureSession.md)

起動中のUnity EditorのProfiler履歴を、指定フレーム数だけ収集して.dataへ保存します。
